# Image Rename Map

This document records the exact mapping of all visual assets reorganized from the flat `/public` directory into purposeful, categorized folders in `/public/images/` and `/public/icons/`.

## Asset Categories

- `/public/images/books/` — Cover artwork and physical book assets
- `/public/images/blogs/` — Editorial article headers and archival document banners
- `/public/images/brand/` — Primary brand identity, seal of authenticity, hero banners
- `/public/images/supporters/` — Author, patron, and archivist portraits
- `/public/images/og/` — OpenGraph social sharing preview cards
- `/public/images/ui/` — User interface icons and navigation cues
- `/public/icons/` — Platform and app manifest icons
